# Safran 2.8.1 — Aleppo interlinear and interface improvements

- Read the Aleppo text (MAM) word by word beneath the Westminster text in the interlinear view. Differences and missing counterparts are marked, and passages lost from the Aleppo Codex are identified.
- English interface labels now include reader tabs and window titles, with additional translated controls and apparatus explanations.
- Show English versions of the LXX, Peshitta and Hexapla reading explanations when the interface is set to English, and translate the witness selection count.
- Simplify the Peshitta interlinear label and update the apparatus documentation and screenshot.

The Aleppo interlinear alignment is generated automatically; it is a reading aid, not an independent critical edition. MAM source attribution and CC BY-SA 4.0 licensing are preserved.

Downloads are provided for macOS (Apple Silicon), Windows (installer and portable), and Linux (AppImage and Debian package).
