# Samaritan Pentateuch materials in Safran

Main Hebrew text, English translation, red MT-difference markings, footnotes
and endnotes: Moshe Florentin and Abraham Tal, *The Samaritan Pentateuch:
An English Translation with a Parallel Annotated Hebrew Text*, Open Book
Publishers, 2024. https://doi.org/10.11647/OBP.0415
The Hebrew edition principally follows MS Nablus 6 (1204).

Source morphology and Tal–Florentin comparison features: Christian Canu
Højgaard, Martijn Naaijer and Stefan Schorch, *Text-Fabric Dataset of the
Samaritan Pentateuch*, CACCHT / DT-UCPH 7.5.0.
https://doi.org/10.5281/zenodo.7734632
https://github.com/DT-UCPH/sp/tree/e8a120f2e92b6558fd39bbe72f830ded871a0a47
The underlying CACCHT text follows Dublin CBL 751, supplemented by Garizim 1,
supplied by the Samaritanus project directed by Stefan Schorch.

Changes in Safran: apply the supplied Tal–Florentin readings to the main text;
convert PDF text, font encodings, red markings and RTL runs to Unicode/HTML;
resolve printed line-end hyphenation while retaining compounds and source
spelling; retain original note references and pages. Transfer CACCHT morphology
only to unchanged forms. Missing features and analyses of new readings remain
unprovided. The source revisions, hashes and coverage are recorded under
tools/samaritan/. The Hebrew edition's legacy file paths remain stable to
support updates of installed copies; metadata identifies Tal–Florentin.
