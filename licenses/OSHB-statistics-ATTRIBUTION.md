# Open Scriptures statistics and lexical root families

Credit: Open Scriptures Hebrew Bible Project.

OSHB word/morphology counts derive from the bundled Westminster Leningrad Codex
(OSHB), licensed CC BY 4.0. Explicit root-family metadata derives from
LexicalIndex.xml and AugIndex.xml in the Open Scriptures HebrewLexicon project:
https://github.com/openscriptures/HebrewLexicon/tree/21c9add13bc727d3a951361778e97e3ff7afd1ce

The project's readme releases these files under Creative Commons Attribution 4.0
International: https://creativecommons.org/licenses/by/4.0/ .
Original compressed snapshots and SHA-256 hashes are retained. Safran extracts
explicit root relationships and aggregates statistics; no guessed lexical
families are added. Root data is incomplete and is not a new critical lexicon.

Textual-evidence metadata is derived separately from the existing Tal–Florentin,
Tov/Kraft CATSS, ETCBC/Abegg DSS, and Digital Kennicott payloads. Their original
attributions, source versions and individual licences are retained in those
payloads and referenced in the statistics index. This count/index does not
relicense any of their textual readings.
