# Sedra data release 2026-10-24

Sedra is the Syriac lexical database of
Beth Mardutho: The Syriac Institute, <https://sedra.bethmardutho.org>. This release holds all of Sedra's
published (verified) lexical data: roots, lexemes, word forms, glosses, etymologies,
the conjugation templates, the sources, and every lookup table. It is regenerated every
week; the newest release is listed in <https://sedra.bethmardutho.org/downloads/latest.json>.

Please use these files rather than requesting the site or the API record by record.

Everything is also in one file: `sedra-2026-10-24.zip`.

**Two formats of the same data:**

1. **Sedra V tables** (`<table>.jsonl.gz`): gzip-compressed [JSON Lines](https://jsonlines.org/),
   one JSON object per row, the columns of Sedra V's database. Ids are Sedra's
   permanent ids (the same as Sedra IV's for everything Sedra IV had). A column ending
   in `_id` refers to the row with that id in the table it names (`lexeme_id` →
   `lexemes`, `kaylo_id` → `kaylos`, `language_id` → `languages`, and so on).
2. **Sedra IV format** (`sedra4/`): every word, lexeme and root exactly as the Sedra IV
   API answered `/api/word/{id}.json`, `/api/lexeme/{id}.json` and `/api/root/{id}.json`
   (one answer per line: the same JSON, with Sedra IV's line breaks and indentation
   removed), with `definitions.json` and
   `semiticLanguages.xsd`. A program written for the Sedra IV API can read these
   unchanged, and the Sedra IV API itself stays: it is Sedra's public API.
   As the Sedra IV API did, `sedra4/words.jsonl.gz` leaves out the words Sedra IV
   could not look up by id (226 here: those stored without a vocalization, for
   which Sedra IV's matching answered "not found"); they are in `words.jsonl.gz`.

**Not in it:**

- the scans of printed lexicon entries and their transcriptions;
- the texts of the Library;
- the verb forms Sedra V generates from its conjugation templates (they may be offered
  later as a separate, labelled file);
- work not yet verified, and every person's account, name or review notes.

## Tables and their Sedra IV columns

Every Sedra IV column of these tables is present. Where Sedra V uses another name:

| Sedra V file | Sedra IV table | Sedra V column ← Sedra IV column |
|---|---|---|
| `roots` | `root` | `sort_text` ← `sorting_text`; `is_high_frequency` ← `high_frequency`; `attested_forms` ← `ia`, `iia`, `iiia`, `iva`, `ip`, `iip`, `iiip`, `ivp` (the stems attested, as a list); `bracket` ← `bracket_type_id` (its name); `translit_sedra3`, `translit_sedra4`, `transliteration_cal`, `translit_leiden`, `translit_hugoye` ← `sedra3`, `sedra4`, `calcode`, `leiden`, `hugoye`; `sedra3_attributes` ← `attributes` |
| `lexemes` | `lexeme` | `radical_type`, `bracket`, `prefix`, `suffix1`, `suffix2`, `suffix3` ← `radical_type_id`, `bracket_type_id`, `prefix_id`, `suffix_prime_id`, `suffix_secunde_id`, `suffix_tertie_id` (their names); `vowel1_id` … `vowel4_id` ← `first_vowel_id` … `fourth_vowel_id`; the transliterations as for roots; `sedra3_attributes` ← `attributes`; `sedra3_morphology` ← `morphological_type`. (`perfect_vowel2_id`, `imperfect_vowel2_id` and `imperfect_vowel3_id` were empty in every Sedra IV row.) |
| `words` | `words` | `syriac_vocalized_west`, `syriac_vocalized_east` ← `vocalized_west_syriac`, `vocalized_east_syriac`; `transliteration_east` ← `vocalized_transliteration`; `is_enclitic` ← `enclitic`; `suffix_type` ← `suffix_type_id` (its name); the transliterations as for roots |
| `glosses` | `gloss` | `notes` ← `comment`; `notes_position` ← `position_id` (before / after); `prefix_italic`, `postfix_italic`, `notes_italic` ← the three `*_font_attributes_id`; `verb_type` ← `verb_type_id` (its name); `sedra3_attributes` ← `attributes` |
| `etymologies` | `etimology` | `source_word` ← `word_origin`; `meaning` ← `comments`; `bracket` ← `bracket_type_id`; `sort_order` ← `sorting` |
| `conjugation_templates` | `conjugation` | `is_base` ← `base` |
| `sources` | `source` | `abbreviation` ← `import_name`; `full_name` ← `fullname` (`copyrighted` is not carried: every source is open in Sedra V) |
| `authors` | `author` | `full_name` ← `fullname` |
| `kaylos` | `kaylo` | `voice` ← its mood; `sort_order` ← `root_order` |
| `languages` | `language` | `iso_code` ← `isocode` |
| `vowels` | `vowel` | `unicode_char` ← `syriac` |
| `category_types`, `stems`, `tenses`, `numbers`, `persons`, `genders`, `states`, `transliteration_schemes`, `transliteration_patterns` | the same | – |

Sedra V adds columns of its own: `review_status` (always `verified` here), `verified_at`,
`origin` (`v4` for rows from Sedra IV, `contributor` for rows added since),
`syr_key` (the letters only, for matching), and the timestamps.

Sedra IV rows not in this release: 2 words and 229 glosses that belong to no lexeme.
