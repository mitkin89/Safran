The same on this place notes: “If DACARU be read, it is taken as ἐξεκέντησαν, that is, _they pierced,_ or _transfixed;_ but if in the contrary order, with the letters interchanged, RACADU, it is understood as ὠρχήσαντο, that is, _they danced._” The same in Epist. LVII to Pammachius (Opp. T. I, p. 311) cites, from memory as it seems, ἐνωρχήσαντο. Our Syriac put ܡܒܙܚܘ, which elsewhere is interchanged with μυκτηρίζειν, ἐκμυκτηρίζειν, καταμωκᾶσθαι (Jerem. xxxviii. 19), and similar words. The Greek lexicographers too, with reference to this place, cite: Κατωρχήσαντο· κατεχάρησαν, ἔπαιξαν (or ἐνέπαιξαν).
